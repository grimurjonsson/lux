Rendering: ANSI → ratatui

How lux's colorized output integrates with ratatui's rendering

The Challenge
// lux Engine outputs ANSI-styled strings: \x1b[1;31mERROR\x1b[0m Connection refused // ratatui expects its own Span/Line types: Line::from(vec![ Span::styled("ERROR", Style::new().bold().red()), Span::raw(" Connection refused"), ]) // Solution: use ratatui's built-in ANSI parsing // ratatui::text::Line has from_ansi() support
Approach: ansi-to-tui bridge
// 1. Read file lines let raw_lines = read_file(path); // 2. Colorize through existing pipeline (unchanged!) let ansi_lines: Vec<String> = raw_lines .iter() .filter(|l| line_filter.check(l)) .map(|l| engine.apply(l)) .collect(); // 3. Convert ANSI → ratatui Lines (one-time on load) let tui_lines: Vec<Line> = ansi_lines .iter() .map(|s| Line::from_ansi(s)) // or ansi_to_tui crate .collect(); // 4. Render visible slice in draw loop let visible = &tui_lines[offset..offset + height]; let paragraph = Paragraph::new(visible.to_vec()); frame.render_widget(paragraph, content_area);
