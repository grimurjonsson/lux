What should the bottom of the pager screen look like?

A

Minimal (less-style)

2024-03-19 ERROR Connection refused
2024-03-19 INFO Server started on :8080
2024-03-19 WARN Slow query detected (2.3s)
2024-03-19 DEBUG Processing request #4521

Just filename, line range, and percentage. Clean and familiar.

Informative

2024-03-19 ERROR Connection refused

Shows active profile, rule count, and key hints. More discoverable.
