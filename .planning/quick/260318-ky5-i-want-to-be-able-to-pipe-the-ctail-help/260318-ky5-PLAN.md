  <action>
Add a "help" profile to the `builtin_profiles()` function in `src/config.rs`, alongside the existing "logs" profile.

The profile should contain rules targeting standard CLI help text patterns (clap, argparse, man-page style). Use "match" scope for most rules so only the matched portion is colored, keeping surrounding text readable.

Rules to include (in this priority order):

1. **Section headers** — lines like "Usage:", "Commands:", "Arguments:", "Options:", "Formats:", "Styles:" etc.
   - Pattern: `^[A-Z][a-zA-Z ]+:$` (line starting with uppercase word(s) followed by colon at end-of-line)
   - Style: `bold+cyan`, scope: `line`

2. **Long flags with values** — `--color`, `--profile`, `--strip-ansi` etc.
   - Pattern: `--[a-zA-Z][-a-zA-Z0-9]*`
   - Style: `bold+green`, scope: `match`

3. **Short flags** — `-r`, `-f`, `-n`, `-h` etc.
   - Pattern: `-[a-zA-Z]` (but not inside `--` long flags, use negative lookbehind: `(?<!--)-[a-zA-Z]\b`)
   - Style: `bold+green`, scope: `match`

4. **Placeholder values** — `<RULES>`, `<COLOR>`, `<FILE>`, `[FILE]`, `[OPTIONS]`, `[COMMAND]` etc.
   - Pattern: `<[A-Z_]+>|\[[A-Z_]+\]`
   - Style: `cyan`, scope: `match`

5. **Default values in brackets** — `[default: auto]`, `[default: 20]`
   - Pattern: `\[default: [^\]]+\]`
   - Style: `dim`, scope: `match`

6. **Possible values list** — `[possible values: auto, always, never]`
   - Pattern: `\[possible values: [^\]]+\]`
   - Style: `dim`, scope: `match`

7. **Subcommand names** — words at the start of indented lines in the Commands section (like "completions", "profile", "help")
   - Pattern: `^  \w[-\w]*`  (two-space indent followed by a word)
   - Style: `yellow`, scope: `match`

8. **Quoted strings** — `"10"`, `"+5"`, `"^==="` etc.
   - Pattern: `"[^"]*"`
   - Style: `magenta`, scope: `match`

9. **Tool name in Usage line** — `ctail` when it appears in the usage line
   - Pattern: `(?<=Usage: )\w+`
   - Style: `bold+white`, scope: `match`

Do NOT set extensions on this profile (help text doesn't come from files with specific extensions).
