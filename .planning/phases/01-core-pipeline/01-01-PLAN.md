    - parse_style("purple") -> Style with XtermColor(129)
    - parse_style("teal") -> Style with XtermColor(30)
    - parse_style("lime") -> Style with XtermColor(118)
    - parse_style("") -> error
    - parse_style("invalid_garbage") -> error with descriptive message
    - parse_style("bg:invalid") -> error
  </behavior>
  <action>
Create `src/color.rs` with a public `parse_style(spec: &str) -> anyhow::Result<owo_colors::Style>` function.

Implementation:
1. Split the spec on `+` to get individual tokens.
2. For each token, match against:
   - Text effects: "bold", "dim", "italic", "underline"
   - Background prefix: starts with "bg:" -> parse the remainder as a color and apply as background
   - Named ANSI 16 colors: "black", "red", "green", "yellow", "blue", "magenta", "cyan", "white", and "bright-" variants
   - Extended named colors mapped to XtermColor indices: orange=208, pink=213, grey/gray=245, purple=129, teal=30, lime=118, brown=130, olive=142, coral=209, lavender=183
   - Hex colors: starts with "#" or "0x" -> parse 6 hex digits into RGB, apply as truecolor
   - 256-color numeric: parseable as u8 -> apply as XtermColor
   - Anything else: return error with message listing the invalid token and suggesting valid options

For background colors, use the corresponding `on_*()` / `on_truecolor()` / `on_color()` methods on Style.

Use `owo_colors::Style` builder pattern throughout -- never hardcode ANSI escape sequences.

Write inline unit tests in a `#[cfg(test)] mod tests` block covering all behaviors listed above. Tests should verify that parse_style succeeds/fails as expected. For success cases, verify the Style produces ANSI output by formatting a test string and checking it differs from the plain string (confirming styling was applied). For specific colors, use `style.style("test").to_string()` and verify it contains the expected ANSI codes.

NOTE on owo-colors API: Use `Style::new()` builder. For dynamic colors at runtime, use `.color(AnsiColors::Red)` for ANSI 16, `.color(XtermColor::from(N))` for 256-color, and `.truecolor(r, g, b)` for RGB. Background equivalents: `.on_color()`, `.on_truecolor()`. If `.color()` doesn't work with the Style builder, fall back to converting all named colors to their RGB values and using `.truecolor()` uniformly.
  </action>
