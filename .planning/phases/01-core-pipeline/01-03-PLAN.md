  <name>Task 1: Implement output module and main entry point with SIGPIPE handling</name>
  <files>src/output.rs, src/main.rs, src/lib.rs</files>
  <action>
Create `src/output.rs` with terminal detection:

```rust
pub enum ColorMode { TrueColor, Color256, Color16, NoColor }

pub fn detect_color_mode(cli_choice: &ColorChoice) -> ColorMode
```

Logic:
1. If cli_choice is Never -> NoColor
2. If cli_choice is Always -> TrueColor (force colors)
3. If cli_choice is Auto:
   - If NO_COLOR env var is set -> NoColor
   - If stdout is not a terminal (use `std::io::IsTerminal`) -> NoColor
   - Otherwise use `supports_color::on(Stream::Stdout)` to detect capability level

Add `color_enabled(&self) -> bool` method on ColorMode (returns true for anything except NoColor).

Update `src/lib.rs` to add `pub mod output;`

Rewrite `src/main.rs` as the entry point:
1. Parse CLI args with `Cli::parse()`
2. Detect color mode with `detect_color_mode(&cli.color)`
3. Build rules with `build_rules(&cli.rules)?` -- exit with error message on invalid rules
4. Create Engine with rules and color_enabled flag
5. Lock stdin and stdout, wrap stdout in BufWriter
6. Read lines from stdin, apply engine, write to stdout using `writeln!`
7. Wrap main logic in `run() -> anyhow::Result<()>`
8. In `main()`, catch errors from `run()`:
   - If BrokenPipe -> `std::process::exit(0)` silently
   - Otherwise -> `eprintln!("ctail: {e:#}")` and exit(1)

CRITICAL: Never use `println!` in the hot loop -- always `writeln!` to BufWriter. This is essential for SIGPIPE handling (println panics on broken pipe, writeln returns Result).
