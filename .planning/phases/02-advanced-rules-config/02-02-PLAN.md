    - scope field defaults to "line" when omitted
    - default_config_path() uses $XDG_CONFIG_HOME if set, falls back to $HOME/.config
    - default_config_path() on macOS uses ~/.config (NOT ~/Library/Application Support) per locked decision
  </behavior>

3. Create src/config.rs with:

   Serde-derived structs matching locked TOML structure:
   ```rust
   #[derive(Deserialize, Default)]
   pub struct Config {
       #[serde(default)]
       pub rules: Vec<RuleConfig>,
       #[serde(default)]
       pub profiles: HashMap<String, ProfileConfig>,
   }

   #[derive(Deserialize)]
   pub struct RuleConfig {
       pub pattern: String,
       pub style: String,
       #[serde(default = "default_scope")]
       pub scope: String,
   }

   fn default_scope() -> String { "line".to_string() }

   #[derive(Deserialize)]
   pub struct ProfileConfig {
       #[serde(default)]
       pub rules: Vec<RuleConfig>,
   }
   ```

   `pub fn default_config_path() -> Option<PathBuf>` - checks `$XDG_CONFIG_HOME`, falls back to `$HOME/.config`, appends `ctail/config.toml`. Do NOT use the `dirs` crate (per locked decision -- it returns ~/Library/Application Support on macOS).

   `pub fn load_config(explicit_path: Option<&Path>) -> Result<Option<(Config, PathBuf)>>`:
   - If explicit path: error if doesn't exist, read and parse
   - If no explicit path: use default_config_path(), return Ok(None) if file doesn't exist
   - Wrap parse errors with file path context: `anyhow!("failed to parse {}: {e}", path.display())`

   Unit tests in `#[cfg(test)] mod tests` using `tempfile::TempDir` for config file tests.
